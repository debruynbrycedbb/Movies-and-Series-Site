# Poster images

Put your own poster images in this folder.

Name each file after the film's id, listed in `POSTER-FILENAMES.txt`
in the project root. For example:

    images/inception.jpg
    images/the-dark-knight.jpg
    images/spider-man-2.jpg

`.jpg`, `.jpeg`, `.png` and `.webp` all work.

Any film you don't supply an image for falls back to the poster the site
finds on Wikipedia, so you can add these a handful at a time — nothing
breaks in the meantime.

## Tips

- Portrait images work best. The slots are 2:3 (e.g. 400x600).
- Keep them under ~200 KB each so the page stays quick. 400px wide is plenty.
- Your files always beat the automatic ones, so dropping an image in here
  is how you override a poster the site got wrong.
- Added an image but still seeing the old one? Hard-refresh with
  Ctrl+Shift+R (Cmd+Shift+R on Mac), or use Settings -> Refresh posters.
